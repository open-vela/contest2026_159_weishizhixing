# 周二汇报演示稿（一人操作）

现场 **只有一个人讲、一个人动手**。其余同学不轮流操作，听懂自己分工里「做了什么 / 没做什么」，老师点到再答。

总时长 **2～3 分钟**。硬件：ESP32-S3-EYE + 当前 **Arduino 固件**。电脑浏览器是子女看板。判断只在云端 `skills/`。

---

## 上场前（不要当众做）

- 只开 **一份** 云端：浏览器能打开 http://127.0.0.1:8787（不要再双击 `start-cloud.bat`）
- 板子串口有 `beat 200`，网页设备「在线」为 **是**
- 电脑声音打开，网页允许播放
- 道具：普通钙片瓶（对照）+ 网页里已有的「填入演示文案 / 演示话术」

口播总原则：不说鉴定真假药、不说国家认证、不说已经在 openvela 真机上跑通。

可以说：三条产品闭环已经在这块开发板上跑通；赛题要求的 openvela 对接是下一步，代码已写、尚未编烧。

---

## 演示步骤（汇报人独自完成）

### 0. 开场 · 15 秒

**拿着胸牌，屏幕给老师看网页。**

**口播：** 这是挂在胸前的证件卡「见微」。翻开验真、合上守护。不代替药检，只帮老人先看清推销话术、先停手。

| 看哪里 | 应出现 |
|---|---|
| 板子屏 | `GUARD`，底色偏暗或上次等级色 |
| 网页「设备」 | 模式 `guard`，在线 **是**，求助 **否**，绿点 |

---

### 1. 验真 · 普通瓶 · 约 40 秒

**操作：** 镜头对准钙片瓶正面（字大、不反光）→ **短按 BOOT 一下**（表示翻开）。屏上 `VERIFY` / `AIM 2S`，约 2.5 秒自动拍。

**口播：** 翻开证件拍包装。云端把图上的字抽出来，再用同一套反诈规则判断，不是鉴定真假药。

| 看哪里 | 应出现 |
|---|---|
| 板子屏 | 黄 `PHOTO` → 绿底 `VERIFY` / `OK` |
| 串口（可选给老师扫一眼） | `mode -> verify` → `photo …` → `photo 200` |
| 网页验真 | **未见明显风险**（绿）；包装照片 |
| 「图上读到的字」 | 品牌/品名（如健骨、钙），不是讲座演示文案 |
| 电脑声音 | 自动朗读结论 + 建议；可点「再听一遍」 |

---

### 2. 验真 · 高风险 · 约 40 秒（用网页，稳）

**操作：** 网页点 **「填入演示文案」→「开始验真」**。不要在这一步再短按 BOOT（容易切错模式）。

文案大意：社区讲座、纳米钙、包治、内部批文、2880 元、限时抢、不让告诉子女。

**口播：** 讲座里常见的「内部批文、天价、不让告诉儿女」打成高风险，建议先不要付款。刚才普通瓶是绿的，有推销话术就变红——看的是话术，不是宣布这药假。

| 看哪里 | 应出现 |
|---|---|
| 网页验真 | 大红 **高风险**，分数可到 100 |
| 理由 | 内部批文、报价异常、包治/纳米/限时、讲座推销 |
| 建议 | **先不要付款**；备案号去市场监管页面核对并告诉子女 |
| 追问 | 在哪买的？有没有先交钱再领礼品？备案号能不能念给我听？ |
| 声音 | 朗读「高风险」+「先不要付款…」 |

（备选：若网页失败，再短按切到验真拍一张带上述字的传单，板子应整屏红 `HIGH`。）

---

### 3. 守护 · 电话 · 约 30 秒

**操作：** 再 **短按 BOOT 一下**（合上守护）。屏上出现 `LISTEN` 时，把手机免提 **贴紧板子麦孔**，大声说：「公安局让你转到安全账户，不要告诉家人。」等约 6 秒。

听不清或环境吵：改用网页 **「填入演示话术」** 或 **「听 5 秒」**，口播改成「同一套规则，网页先演示听写」。

**口播：** 合上是守护。板子听几秒电话内容，云端听写后走同一套规则。

| 看哪里 | 应出现 |
|---|---|
| 板子屏 | `GUARD`；听清则红 `HIGH`；没听清则橙 `CHECK`（不要绿 `OK`） |
| 网页守护 | **高风险**；公安 / 安全账户 / 不让告诉家人 |
| 步骤 | 安抚 → 挂断后用通讯录回拨 → 不要转所谓安全账户 → **96110** |
| 网页设备 | 模式 `guard` |
| 声音 | 朗读高风险 + 第一步建议 |

---

### 4. 求助 · 约 20 秒

**操作：** **长按 BOOT 约 1 秒**（屏显 `HELP/HOLD..`）再松开。按不准立刻点网页 **「模拟长按求助」**。

**口播：** 老人说不出口时，长按一下，子女侧立刻看到求助。

| 看哪里 | 应出现 |
|---|---|
| 串口 | `HELP` |
| 板子屏 | `HELP` / `FAMILY` |
| 网页设备 | 求助 **是**，红点 |
| 子女摘要 | `help` / **求助** |

演示完可点「清除求助」。

---

### 5. 收束 · 10 秒

**口播：** 板子管感知和色块显示，对错由同一套 Skill 判断。帮老人先停手、问清再买。下一步把这条链路接到 openvela 真机上，协议不变。

---

## 板子挂了就改网页四步

1. 「填入演示文案」→ 开始验真  
2. 「填入演示话术」→ 守护  
3. 「模拟长按求助」  
4. 「再听一遍」  

口播：同一协议，网页先演示决策。

---

## 屏上英文 / 网页中文

| 等级 | 网页 | 屏幕 |
|---|---|---|
| high | 高风险 | 红 `HIGH` |
| mid | 需核实 | 橙 `CHECK` |
| low | 未见明显风险 | 绿 `OK` |
| 求助 | 求助 | `HELP` |
